# Relevance-Classifier Validation Gate — Sample Sets Drawn & Labelled

**Date:** 2026-09-01. **Design:** `2026-08-31-relevance-classifier-design.md`
(e601648) §3.9 (the three sample sets) and §3.10 (the labelling rubric).
**Type:** read-only against production; writes only the committed artifacts
under `brain/decisions/gate-sets-2026-09-01/`. **Tagging:** `[V]` verified
this session.

**Why now, before the LLM stage exists:** the classifier's LLM stage is not
built. Drawing and labelling the held-out gate now makes it structurally
impossible to tune the classifier against it, even inadvertently. Once the
LLM exists this property is gone. Nothing in this task builds, prompts, or
runs any classifier; no `category` / `category_source` /
`category_classification_log` row is written.

## PART 1 — THE DRAW

### Seed & procedure `[V]`

- **`GATE_SEED = 20260901`**, `random.Random(20260901)`.
- Frame rows sorted by `market_id`. `rng.sample(range(len(frame)),
  len(frame))` produces one deterministic consumption order per frame; the
  draw walks that order, skips any contaminated pick (below), and takes the
  first **350** clean rows from the EXCLUDE frame and the first **150** clean
  rows from the RESIDUAL frame.
- **EXCLUDE split:** `sample[:200] → set_c`, `sample[200:350] → set_a`.
  `set_a` and `set_c` are therefore **disjoint by construction** — a
  deliberate strengthening over §3.9 (which describes them as independent
  draws); it removes any "same market scored in two metrics" objection.
- `set_b` is drawn from the RESIDUAL frame after `set_a`/`set_c`; disjoint
  from both (different frame). All three pairwise-disjoint, asserted in code.

### Frames `[V]`

| frame | definition | size |
|---|---|---:|
| Unknown population | `markets.category = 'Unknown'`, non-empty title | 778,982 |
| **EXCLUDE** (`set_a`, `set_c`) | above ∧ `relevance_prefilter.prefilter(title) == 'EXCLUDE'` | **634,715** |
| **RESIDUAL ∧ no-keyword** (`set_b`) | above ∧ `prefilter(title) == 'RESIDUAL'` ∧ no M9 keyword | **125,208** |

**"No election/geopolitics token"** (§3.9's phrase for the `set_b` frame) is
operationalised as **M9's `KEYWORD_FILTER`** — the 39-token positive list in
`scripts/backfill_market_categories.py`, matched with M9's own semantics
(`LOWER(title) LIKE '%kw%'`, bare substring). `relevance_prefilter.py`
deliberately carries no positive list, so M9's is the canonical
"election/geopolitics token" set the design refers to (design §1.3). The
list is recorded verbatim in `manifest.json`. Substring semantics are
deliberately kept (not word-boundary) — they only *widen* what `set_b`
excludes, keeping `set_b` strictly the genuinely-ambiguous middle.

`set_b` staged-slug coverage: **62 / 150** have `market_slug` / `event_slug`
/ `event_title` from `relevance_slug_staging` (the swept + unswept residual
slug fetches); the other 88 are title-only. Per §3.10 slugs are used "where
available"; missing slugs push a labelling call toward `borderline →
NotRelevant`, which is the intended conservative default.

### Contamination check (mandatory) `[V]`

`2026-08-31-prefilter-implementation.md` records that **zero `market_id`s
were inspected** while drafting the pre-filter token lists — every pattern
traces to a committed doc or the task prompt, and
`measure_prefilter_coverage.py` prints "aggregate counts only — never a
title". This check verifies that claim holds for the drawn 500.

- **Corpus:** 15 files — the 6 provenance-cited decision docs
  ([D1]–[D4] + the record doc), 5 adjacent classifier docs, and the
  pre-filter module + its test + its coverage script + `detect_insider_activity.py`
  (the [D3] `_EXCLUSION_KEYWORDS` source). 315,475 chars; **1** `0x…64hex`
  id present in the whole corpus. (Over-inclusive on purpose — a wider
  corpus can only reject more.)
- **Test, per drawn row:** `market_id` ∈ corpus's `0x`-id set; **or** the
  row's `title` (≥ 20 chars) appears verbatim as a substring; **or** a
  staged `market_slug` / `event_slug` / `event_title` (≥ 15 chars) appears
  verbatim. Case-insensitive. A contaminated pick is dropped and replaced by
  the next clean pick from the same stream.
- **Result: 4 picks excluded, all from the EXCLUDE frame, all the generic
  template title `"Games Total: O/U 2.5"`** — quoted as a skip-sample row in
  `2026-08-30-category-classifier-investigation.md`. These are template
  *instances* (hundreds of distinct markets share that exact title; none was
  individually inspected), but the rule is applied literally: excluded,
  redrawn, and recorded in `manifest.json → contamination_check.exclusions`.
  **Zero exclusions from `set_b`.** No drawn `market_id` appeared anywhere in
  the corpus.
